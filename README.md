# AKCIT-algebra_por_proprieadades_requisitos
Aretefatos de requisitos do projeto Algebra por propriedades

# Software de Resolução Algébrica Passo a Passo

## Visão Geral
Aplicação que permite ao aluno resolver equações do primeiro grau aplicando
explicitamente as propriedades algébricas dos conjuntos ℕ, ℤ e ℚ e as
propriedades da igualdade — sem atalhos como "passa para o outro lado".

## Objetivo Pedagógico
Tornar visíveis as propriedades matemáticas que a terminologia prática esconde.

## Escopo (a confirmar — ver D01)
- Equações do 1º grau: `ax + b = cx + d`
- Conjuntos universo: ℕ, ℤ, ℚ
- Resolução passo a passo com justificativa por propriedade
- Validação de aplicabilidade e de pertinência da solução ao universo
